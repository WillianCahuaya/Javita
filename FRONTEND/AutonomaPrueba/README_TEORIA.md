GITHUB
*******
git status                      >>> Visualiza el estado de los cambios
git add .                       >>> Agregad cambios al stage
git commit -m "mi mensaje"      >>> commitear el cambios
git push origin develop         >>> Subir tu cambios a la plataforma github

git pull origin develop         >>> bajar los cambios

git stash                       >>> guarda teporalmene en tu memoria de git
git stash pop                   >>> recupera lo guardado en la memoria git y lo elimina
